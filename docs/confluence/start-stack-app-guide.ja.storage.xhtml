2. コマンドを作成する

960
  1. 言語 — English または 日本語（UI 全体が両言語対応です）。
  2. 新しいコマンドを作成（1）。
  3. 車両 — 数字だけ入力: 807 で truck-807 になります。back / quit と入力して移動もできます。
  4. 起動設定 — 前回の選択が先頭に固定されています。Enter で採用。
  5. ルート（任意）— §3 を参照。空欄 + Enter でルートなし。
  6. 日本走行モード — はい/いいえ（日本語を選んだ場合の初期値は「はい」）。

コマンドはフラグごとに1行で表示され（シェルにそのまま貼り付け可）、すでにクリップボードにあります。この選択内容をプリセットとして保存しますか？ に答えれば保存できます。

3. ルート選択: 入力してオートコンプリート

960

ルート名またはマップ名 の数文字を入力すると、180以上のルートがその場で絞り込まれます。Tab（または →）でハイライトされた候補を確定、↑/↓ で移動、空欄で ↓ を押すと全件表示。候補は マップ — ルート の形式です。

4. クローズドループ走行モード（日本）

960

クローズドループ走行ルートを作成（日本）（6）で、基本コマンド（車両・起動設定 — 日本走行モードは強制的に有効）を尋ねられ、次に各停留所（ルート）を走行順に、同じオートコンプリート選択で追加します。空行、done、または -- ルート完了 -- の行で終了。back で直前の停留所を削除。名前を付けて保存 — 最大4ループ、Q/W/E/R に対応します。

ループの走行では、停留所1のコマンドが表示（コピー）され、走行中は待機し、次に停留所2…最後の停留所の後は停留所1に戻って次の周回へ。あなたが「完了」と言うまで続き、走行した周回数を報告します。

5. プリセット: 個人・共有・書き出しと読み込み

960
  • 個人プリセット はウィザード / Web フォームから保存され、自分のマシンだけに存在します。
  • 共有プリセット はリポジトリの presets/ フォルダにあり、全マシンに （共有） 付きで表示されます。変更・削除はリポジトリでのみ可能です。
  • 共有プリセットと同名の個人プリセットは、ローカルで優先されます。
自分のプリセットをチームと共有する
  1. TUI: プリセットを書き出して共有 → 選択 → ファイルが exports/<名前>.json に書き出されます。
    Web: プリセットを選択 → 書き出す → ブラウザが <名前>.json をダウンロードします。
  2. そのファイルをリポジトリ管理者に送ります（Slack、メール、PR）。
  3. 管理者が presets/ に配置してプッシュ。次回起動時に全員のアプリに反映されます — どこでも再入力は不要です。

誰かから受け取ったファイルを読み込む: TUI プリセットファイルを読み込む → パス入力。Web プリセットファイルを読み込む → ファイルを選択 → 読み込む。個人プリセットになります。

共有できるのは値プリセット（車両 / 起動設定 / ルート / 日本走行モード）だけです。カスタムの生コマンドプリセットは個人用のままです — 共有の目的は、どのマシンでも正しく再構築できるルート設定だからです。

6. Web UI

960

TUI と同じ選択肢・プリセット・履歴をブラウザで。右上の 日本語 / English リンクで言語を切り替えます。ルート欄はコンボボックス: クリックでマップごとにグループ化された全一覧、入力で絞り込み、クリックまたは ↑/↓ + Enter で選択。コマンドを作成 でコマンドが表示されます（自動コピー）。プリセットはドロップダウンから読み込み / 削除 / 書き出し。読み込みフォームは .json ファイルを受け付けます。

7. トラック関連の機能と画面録画

  • トラックから最新の実行IDを取得（3）— ケーブル接続中のトラックに SSH し、最新の run id をコピーします。
  • トラックのSSHをセットアップ（4）— トラックごとに1回: トラック番号の名前で鍵とエイリアスを作成。
  • 画面録画 — 各コマンドの後に確認（r / q）、または 画面録画のみ（2）/ ./recorder.sh で単独実行。保存か破棄を選び、run id と Polarion テストケース ID でファイル名が決まります。
