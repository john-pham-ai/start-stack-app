Two interfaces, one tool. ./launch.sh (or the launch alias) opens the keyboard-first wizard; ./run.sh serves the web UI at http://127.0.0.1:5050. Both build the same start_stack command, share presets and history, and put the result on your clipboard. Repo: john-pham-ai/start-stack-app · 日本語版はこちら

Get the tool (once)

960 Repository

github.com/john-pham-ai/start-stack-app — clone it, run one script, and you're on the start menu. After that the tool keeps itself up to date from this repo (see the next section), so a clone is a one-time step.
  1. Open a terminal and clone the repo: bash
  2. Run the launcher — the first run builds the Python venv, installs the dependencies, and adds a launch alias to your shell (about a minute): bash
  3. Pick your language — you're on the start menu. From the next terminal on, just type launch from anywhere. For the browser version, ./run.sh and open http://127.0.0.1:5050.

Requirements: git and python3 (3.10+) with the venv module — on Ubuntu, sudo apt install python3-venv if the launcher asks for it. Access to GitHub for the clone, the self-update, and the routes sync. Optional: a local brain2 checkout at ~/brain2 (or BRAIN2_REPO_PATH) as an offline fallback for the route list.

1. The start menu & shortcut keys

960

After picking the language, every menu entry has a shortcut: press the key, then Enter.

KeysGroup
1 2 3 …Fixed entries — build, record-only, truck fetch, SSH setup, save custom, build loop, export/import, quit
! @ # $ % ^ & * ( )Presets, in save order — repo-shared ones are marked (shared)
Q W E RJapan closed loops (4 max — one key per loop)
A S D FRecent runs — the last 4, at the bottom of the menu

Picking a preset or a recent run prints the command, copies it, and offers to record the screen (r to record, q to skip). The menu returns after every flow; only Quit exits.

2. Building a command

960
  1. Language — English or 日本語 (the whole UI is bilingual).
  2. Build a new command (1).
  3. Vehicle — type just the number: 807 becomes truck-807. Type back / quit to navigate.
  4. Launch config — your last pick is pinned first; Enter takes it.
  5. Route (optional) — see §3. Blank + Enter means no route.
  6. Japan driving — Yes/No (defaults to Yes if you picked 日本語).

The command prints one flag per line (shell-pasteable) and is already on your clipboard. Answer Save these choices as a preset? to keep it.

3. The route prompt: type to autofill

960

Type a few letters of a route name or a map name — both filter the 180+ routes live. Tab (or →) accepts the highlighted suggestion; ↑/↓ browse; ↓ on an empty line shows everything. Suggestions read map — route.

4. Closed-loop mileage mode (Japan)

960

Build a closed-loop mileage route (Japan) (6) asks for the base command (vehicle, launch config — Japan driving is forced on), then each stop (a route) in driving order with the same autofill picker. Finish with a blank line, done, or the -- route done -- row; back removes the last stop. Name it and it's saved — 4 loops max, mapped to Q/W/E/R.

Driving a loop prints stop 1's command (copied), waits while you drive, then stop 2 … after the last stop it wraps back to stop 1 for another lap, until you say the run is done. It reports the laps driven.

5. Presets: personal, shared, export & import

960
  • Personal presets are saved from the wizard / web form and live only on your machine.
  • Shared presets live in the repo's presets/ folder and appear on every machine, marked (shared). They can only be changed or removed in the repo.
  • A personal preset with the same name as a shared one wins locally.
Sharing your preset with the team
  1. TUI: Export a preset to share → pick it → the file lands in exports/<name>.json.
    Web: select the preset → Export → the browser downloads <name>.json.
  2. Send that file to the repo owner (Slack, email, or a PR).
  3. The owner drops it into presets/ and pushes. Everyone's app picks it up on the next launch — no re-typing anywhere.

Importing a file someone sent you: TUI Import a preset file → path; Web Import a preset file → choose the file → Import. It becomes a personal preset.

Only values presets (vehicle / launch config / route / Japan toggle) can be shared. Raw custom-command presets stay personal — the point of sharing is a route setup that rebuilds correctly on any machine.

6. The web UI

960

Same options, presets and history as the TUI, in the browser. The route box is a combobox: click for the full list grouped by map, type to filter, click or ↑/↓ + Enter to pick. Build command shows the command (auto-copied). Presets load / remove / export from the dropdown; the import form takes a .json file.

7. Truck helpers & screen recording

  • Fetch the latest Run ID from the truck (3) — SSHes to the cabled truck and copies the newest run id.
  • Set up SSH for a truck (4) — one-time per truck: an identity and alias named after the truck number.
  • Record the screen — offered after every command (r / q), or standalone via Record the screen only (2) / ./recorder.sh. Keep or discard, then a run id and Polarion test-case id name the file.
