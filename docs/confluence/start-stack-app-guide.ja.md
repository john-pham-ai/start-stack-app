## これは何か

`start_stack` の起動コマンドを、フラグを覚えずに組み立てるための小さなローカルツールです。
2つのインターフェースが選択肢・プリセット・履歴を共有します:

- **TUI** — `./launch.sh`（または `launch` エイリアス）: キーボード操作のウィザード
- **Web UI** — `./run.sh` → <http://127.0.0.1:5050/?lang=ja>

どちらも次のようなコマンドを作成し、クリップボードにコピーします:

```
start_stack \
  --vehicle_name truck-807 \
  --launch_config sds_road_readiness \
  --route shoreline_straight \
  --enable_japan_driving
```

## ツールの入手（初回のみ）

**動画:** `ja-07-setup-clone.mp4`

**リポジトリ: <https://github.com/john-pham-ai/start-stack-app>** — クローンして
スクリプトを1つ実行すればスタートメニューへ。以後はツールが自動更新されるため、
クローンは一度だけです。

1. クローン:
   ```
   git clone https://github.com/john-pham-ai/start-stack-app.git
   cd start-stack-app
   ```
2. 初回起動 — venv 作成・依存関係インストール・`launch` エイリアス追加（約1分）:
   ```
   ./launch.sh
   ```
3. 言語を選べばスタートメニュー。次回からは `launch`、Web UI は `./run.sh` →
   <http://127.0.0.1:5050/?lang=ja>。

**必要なもの:** `git`、`python3` 3.10+（`venv` 付き。Ubuntu は `sudo apt install python3-venv`）、
GitHub アクセス。任意: `~/brain2` のローカルチェックアウト（オフライン用フォールバック）。

## アプリは自動的に最新に保たれます

| 対象 | 仕組み | 設定 |
|---|---|---|
| **アプリのコード** | 起動時に自身の GitHub リポジトリを fetch し、origin が進んでいれば fast-forward。新コードは次回起動から有効。未コミットの変更は上書きしません。 | `APP_UPDATE=off` |
| **ルート / マップ** | `brain2` のルート専用 sparse クローンを `~/.cache/start-stack-app/routes` に保持し起動時に更新（≤1回/分）。ローカルチェックアウト → `options.csv` へフォールバック。 | `ROUTES_SYNC=off` |
| **共有プリセット** | リポジトリの `presets/` にコミットされた JSON — アプリ更新と一緒に届く。 | — |

## 1. スタートメニューとショートカットキー

**動画:** `ja-01-start-menu-shortcuts.mp4`

言語選択の後、すべての項目にショートカットがあります: **キーを押して Enter**。

| キー | グループ |
|---|---|
| `1` `2` `3` … | 固定項目（作成・録画のみ・実行ID取得・SSHセットアップ・カスタム保存・ループ作成・書き出し/読み込み・終了） |
| `!` `@` `#` `$` `%` `^` `&` `*` `(` `)` | **プリセット**（保存順。リポジトリ共有は *（共有）* 表示） |
| `Q` `W` `E` `R` | **日本のクローズドループ**（最大4 — ループごとに1キー） |
| `A` `S` `D` `F` | **最近の実行** — 直近4件、メニュー最下部 |

## 2. コマンドを作成する

**動画:** `ja-02-build-command.mp4`

1. **言語** — English または 日本語
2. **新しいコマンドを作成**（`1`）
3. **車両** — 数字だけ入力: `807` → `truck-807`。`back`/`quit` で移動
4. **起動設定** — 前回の選択が先頭。Enter で採用
5. **ルート**（任意）— §3 参照。空欄 + Enter でなし
6. **日本走行モード** — はい/いいえ（日本語選択時の初期値は「はい」）

## 3. ルート選択: 入力してオートコンプリート

**動画:** `ja-03-route-autofill.mp4`

**ルート名またはマップ名** の数文字で180以上のルートを絞り込み。**Tab**（→）で確定、↑/↓ で移動、空欄で ↓ を押すと全件。候補は `マップ — ルート` 形式。

## 4. クローズドループ走行モード（日本）

**動画:** `ja-04-closed-loop.mp4`

**クローズドループ走行ルートを作成（日本）**（`6`）→ 基本コマンド（日本走行モードは強制有効）→ 各**停留所**を走行順に追加。空行・`done`・*-- ルート完了 --* で終了、`back` で直前を削除。名前を付けて保存（最大4 → `Q`/`W`/`E`/`R`）。

**走行**は停留所を順に進み、最後の後は停留所1へ戻って周回。「完了」と言うまで続きます。

## 5. プリセット: 個人・共有・書き出しと読み込み

**動画:** `ja-05-shared-presets.mp4`

- **個人プリセット** — 自分のマシンだけ
- **共有プリセット** — リポジトリの `presets/`、全マシンに *（共有）* 付きで表示。変更はリポジトリのみ
- 同名なら個人が**優先**

**共有する:** TUI **プリセットを書き出して共有** → `exports/<名前>.json` / Web **書き出す** → ダウンロード → 管理者に送る → `presets/` にコミット → 全員に自動反映。

**読み込む:** TUI **プリセットファイルを読み込む** → パス / Web → ファイル選択 → **読み込む**。

共有できるのは値プリセット（車両/起動設定/ルート/日本走行）のみ。

## 6. Web UI

**動画:** `ja-06-web-ui.mp4`

右上の **日本語 / English** で切替。ルート欄はコンボボックス（クリックで全件、入力で絞り込み、↑/↓ + Enter で選択）。**コマンドを作成** で表示 + 自動コピー。プリセットはドロップダウンから読み込み/削除/書き出し。

## 7. トラック関連と画面録画

- **トラックから最新の実行IDを取得**（`3`）
- **トラックのSSHをセットアップ**（`4`）— トラックごとに1回
- **画面録画** — 各コマンド後（`r` / `q`）、または **画面録画のみ**（`2`）

## 環境変数

| 変数 | デフォルト | 用途 |
|---|---|---|
| `APP_UPDATE` | オン | `off` で自己更新スキップ |
| `ROUTES_SYNC` | オン | `off` で GitHub ルート同期スキップ |
| `ROUTES_REMOTE_URL` / `ROUTES_BRANCH` | brain2 / `master` | 同期元 |
| `ROUTES_CACHE_DIR` | `~/.cache/start-stack-app/routes` | キャッシュの場所 |
| `BRAIN2_REPO_PATH` | `~/brain2` | ローカルフォールバック |
| `TRUCK_SSH_TARGET` | `applied@192.168.1.11` | トラック SSH 先 |

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| `（start-stack-app の <hash> が利用可能です…）` | `git stash` かコミットして再起動 |
| ルートが古い/ない | `rm -rf ~/.cache/start-stack-app/routes`。オフラインは `~/brain2` で `git pull` + `ROUTES_SYNC=off` |
| 共有プリセットが出ない | ファイルが不正 — 管理者に `presets/<名前>.json` の修正依頼 |
| 「ループが満杯です」 | 最大4 — **保存したループを削除** |
| トラックに到達できない | ケーブル/ネットワーク確認、**トラックのSSHをセットアップ** |
